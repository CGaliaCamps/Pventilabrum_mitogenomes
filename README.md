# Phakellia ventilabrum mitogenomes

This github space offers all the necessary material to replicate the manuscript entitled "Demosponge (Porifera) mitogenomes reflect latitudinal population structure, reveal intraspecific structural variation, and functionally confirm a novel 16S intron"

This repository is organised in three folders:
- Alignments: Here we have deposited all single-gene alignments, so you can easily use them
- Annotations: Here you will fing the annotations missing in the NCBI
- Scripts: If you want to replicate the study using the reads from the ENA, come here
